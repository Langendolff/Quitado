# Contas Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Flutter (Android + Linux) para contas a pagar com recorrência mensal, lembretes, lançamentos de receitas/gastos, resumo mensal e backup JSON.

**Architecture:** Lógica pura (`logica.dart`) e modelos (`models.dart`) sem Flutter, testados por unidade. `db.dart` encapsula SQLite (sqflite; ffi no Linux e nos testes). `lembretes.dart` agenda notificações só no Android. Telas em `lib/telas/`, cada uma carrega seus dados via `FutureBuilder` e recarrega com `setState`. `db` e `prefs` são globais em `main.dart` (app pessoal, um usuário).

**Tech Stack:** Flutter 3.44 / Dart 3.12, sqflite, sqflite_common_ffi, path_provider, shared_preferences, flutter_local_notifications, timezone, share_plus, file_selector, flutter_localizations.

Spec: `docs/superpowers/specs/2026-10-31-contas-design.md`

## Global Constraints

- Plataformas: Android e Linux desktop. Nada de iOS/Web/Windows/macOS.
- Valores sempre em **centavos (int)**; datas armazenadas como ISO `YYYY-MM-DD`.
- Categorias fixas: Moradia, Alimentação, Transporte, Saúde, Lazer, Salário, Outros.
- `dias_aviso` em `shared_preferences`, padrão 1. Lembrete às 09:00, `dias_aviso` dias antes do vencimento.
- Recorrência só mensal; próximo vencimento = mesmo dia do mês seguinte, limitado ao último dia do mês.
- Pagar conta = uma transação: marca paga + cria gasto + (se recorrente) cria próxima.
- Importação inválida não altera nada.
- Textos da UI em português.

```dart
  final n = DateTime.now();

DateTime? _data(Object? s) => s == null ? null : DateTime.parse(s as String);

  final int valor; // centavos
```

```dart
import 'models.dart';

const meses = ['Janeiro', 'Fevereiro', 'Março', 'Abril', 'Maio', 'Junho', 'Julho',
  'Agosto', 'Setembro', 'Outubro', 'Novembro', 'Dezembro'];

DateTime proximoVencimento(DateTime v) {
  final ultimoDia = DateTime(v.year, v.month + 2, 0).day; // dia 0 = último do mês anterior
  return DateTime(v.year, v.month + 1, v.day > ultimoDia ? ultimoDia : v.day);
}

enum Situacao { atrasada, proxima, normal }

Situacao situacao(Conta c, DateTime hoje, int dias) {
  if (c.vencimento.isBefore(hoje)) return Situacao.atrasada;
  if (!c.vencimento.isAfter(DateTime(hoje.year, hoje.month, hoje.day + dias))) {
    return Situacao.proxima;
  }
  return Situacao.normal;
}

class Resumo {
  final int receitas, gastos, aPagar;
  final Map<String, int> porCategoria;
  const Resumo(this.receitas, this.gastos, this.aPagar, this.porCategoria);
  int get saldo => receitas - gastos;
}

Resumo resumoMes(int ano, int mes, List<Lancamento> lancs, List<Conta> contasAbertas) {
  bool noMes(DateTime d) => d.year == ano && d.month == mes;
  var receitas = 0, gastos = 0, aPagar = 0;
  final porCategoria = <String, int>{};
  for (final l in lancs.where((l) => noMes(l.data))) {
    if (l.tipo == 'receita') {
      receitas += l.valor;
    } else {
      gastos += l.valor;
      porCategoria[l.categoria] = (porCategoria[l.categoria] ?? 0) + l.valor;
    }
  }
  for (final c in contasAbertas.where((c) => noMes(c.vencimento))) {
    aPagar += c.valor;
  }
  return Resumo(receitas, gastos, aPagar, porCategoria);
}

String reais(int c) {
  final inteiro = (c.abs() ~/ 100)
      .toString()
      .replaceAllMapped(RegExp(r'\B(?=(\d{3})+(?!\d))'), (_) => '.');
  final cent = (c.abs() % 100).toString().padLeft(2, '0');
  return '${c < 0 ? '-' : ''}R\$ $inteiro,$cent';
}

/// "1.234,56" → 123456. Sem vírgula, o ponto é decimal ("12.50" → 1250).
/// Retorna null se inválido ou <= 0.
int? lerCentavos(String t) {
  var s = t.trim();
  s = s.contains(',') ? s.replaceAll('.', '').replaceAll(',', '.') : s;
  final v = double.tryParse(s);
  if (v == null || v <= 0) return null;
  return (v * 100).round();
}

String centavosTexto(int c) => (c / 100).toStringAsFixed(2).replaceAll('.', ',');

String dataBr(DateTime d) =>
    '${d.day.toString().padLeft(2, '0')}/${d.month.toString().padLeft(2, '0')}/${d.year}';
```

```dart
import 'package:sqflite/sqflite.dart';

import 'logica.dart';
import 'models.dart';

class Db {
  final Database _db;
  Db._(this._db);

  static Future<Db> abrir(DatabaseFactory f, String path) async {
    final db = await f.openDatabase(path,
        options: OpenDatabaseOptions(
          version: 1,
          onCreate: (db, _) async {
            await db.execute('''CREATE TABLE contas(
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              descricao TEXT NOT NULL,
              valor INTEGER NOT NULL,
              vencimento TEXT NOT NULL,
              recorrente INTEGER NOT NULL,
              categoria TEXT NOT NULL,
              pago_em TEXT)''');
            await db.execute('''CREATE TABLE lancamentos(
              id INTEGER PRIMARY KEY AUTOINCREMENT,
              tipo TEXT NOT NULL CHECK(tipo IN ('receita', 'gasto')),
              descricao TEXT NOT NULL,
              valor INTEGER NOT NULL,
              data TEXT NOT NULL,
              categoria TEXT NOT NULL,
              conta_id INTEGER)''');
          },
        ));
    return Db._(db);
  }

  Future<void> fechar() => _db.close();

  Future<List<Conta>> contasEmAberto() async =>
      (await _db.query('contas', where: 'pago_em IS NULL', orderBy: 'vencimento, id'))
          .map(Conta.fromMap)
          .toList();

  Future<int> _salvar(String tabela, Map<String, Object?> m) async {
    final id = m['id'] as int?;
    if (id == null) return _db.insert(tabela, m);
    await _db.update(tabela, m, where: 'id = ?', whereArgs: [id]);
    return id;
  }

  Future<int> salvarConta(Conta c) => _salvar('contas', c.toMap());

  Future<void> excluirConta(int id) => _db.delete('contas', where: 'id = ?', whereArgs: [id]);

  Future<List<Lancamento>> lancamentosDoMes(int ano, int mes) async {
    final prefixo = '$ano-${mes.toString().padLeft(2, '0')}-%';
    return (await _db.query('lancamentos',
            where: 'data LIKE ?', whereArgs: [prefixo], orderBy: 'data DESC, id DESC'))
        .map(Lancamento.fromMap)
        .toList();
  }

  Future<int> salvarLancamento(Lancamento l) => _salvar('lancamentos', l.toMap());

  Future<void> excluirLancamento(int id) =>
      _db.delete('lancamentos', where: 'id = ?', whereArgs: [id]);

  Future<Conta?> pagar(Conta c, DateTime dia) => _db.transaction((t) async {
        await t.update('contas', {'pago_em': iso(dia)}, where: 'id = ?', whereArgs: [c.id]);
        await t.insert(
            'lancamentos',
            Lancamento(
                    tipo: 'gasto', descricao: c.descricao, valor: c.valor,
                    data: dia, categoria: c.categoria, contaId: c.id)
                .toMap());
        if (!c.recorrente) return null;
        final nova = Conta(
            descricao: c.descricao, valor: c.valor,
            vencimento: proximoVencimento(c.vencimento),
            recorrente: true, categoria: c.categoria);
        return nova.comId(await t.insert('contas', nova.toMap()));
      });

  Future<Map<String, Object?>> exportar(int diasAviso) async => {
        'versao': 1,
        'dias_aviso': diasAviso,
        'contas': await _db.query('contas'),
        'lancamentos': await _db.query('lancamentos'),
      };

  Future<int> importar(Map<String, Object?> d) async {
    if (d['versao'] != 1) throw const FormatException('Versão de backup desconhecida');
    final List<Conta> contas;
    final List<Lancamento> lancs;
    try {
      contas = (d['contas'] as List)
          .map((m) => Conta.fromMap(Map<String, Object?>.from(m as Map)))
          .toList();
      lancs = (d['lancamentos'] as List)
          .map((m) => Lancamento.fromMap(Map<String, Object?>.from(m as Map)))
          .toList();
    } catch (_) {
      throw const FormatException('Arquivo de backup inválido');
    }
    if (lancs.any((l) => l.tipo != 'receita' && l.tipo != 'gasto')) {
      throw const FormatException('Arquivo de backup inválido');
    }
    await _db.transaction((t) async {
      await t.delete('contas');
      await t.delete('lancamentos');
      for (final c in contas) {
```

```dart
import 'dart:io';

import 'package:flutter_local_notifications/flutter_local_notifications.dart';
import 'package:timezone/data/latest_all.dart' as tzdata;
import 'package:timezone/timezone.dart' as tz;

import 'logica.dart';
import 'models.dart';

/// Notificações agendadas só no Android; no Linux tudo é no-op
/// (o aviso desktop aparece ao abrir o app, ver main.dart).
class Lembretes {
  static final _plugin = FlutterLocalNotificationsPlugin();
  static bool get suportado => Platform.isAndroid;

  static Future<void> iniciar() async {
    if (!suportado) return;
    tzdata.initializeTimeZones();
    await _plugin.initialize(const InitializationSettings(
        android: AndroidInitializationSettings('@mipmap/ic_launcher')));
    await _plugin
        .resolvePlatformSpecificImplementation<AndroidFlutterLocalNotificationsPlugin>()
        ?.requestNotificationsPermission();
  }

  static Future<void> agendar(Conta c, int dias) async {
    if (!suportado || c.id == null || c.pagoEm != null) return;
    final v = c.vencimento;
    final quando = DateTime(v.year, v.month, v.day - dias, 9);
    if (quando.isBefore(DateTime.now())) return;
    // ponytail: instante local convertido para UTC; dispensa descobrir o fuso do aparelho
    await _plugin.zonedSchedule(
      c.id!,
      dias == 0 ? 'Conta vence hoje' : 'Conta vence em $dias dia(s)',
      '${c.descricao} — ${reais(c.valor)}',
      tz.TZDateTime.from(quando, tz.UTC),
      const NotificationDetails(
          android: AndroidNotificationDetails('vencimentos', 'Vencimentos')),
      androidScheduleMode: AndroidScheduleMode.inexactAllowWhileIdle,
    );
  }

  static Future<void> cancelar(int id) async {
    if (suportado) await _plugin.cancel(id);
  }

  static Future<void> reagendarTodos(List<Conta> contas, int dias) async {
    if (!suportado) return;
    await _plugin.cancelAll();
    for (final c in contas) {
      await agendar(c, dias);
    }
  }
}
```

- [ ] **Step 1: `lib/telas/config.dart`**

```dart
import 'dart:convert';
import 'dart:io';

import 'package:file_selector/file_selector.dart';
import 'package:flutter/material.dart';
import 'package:path_provider/path_provider.dart';
import 'package:share_plus/share_plus.dart';

import '../lembretes.dart';
import '../main.dart';
import '../models.dart';

class ConfigTela extends StatefulWidget {
  const ConfigTela({super.key});
  @override
  State<ConfigTela> createState() => _ConfigTelaState();
}

class _ConfigTelaState extends State<ConfigTela> {
  void _msg(String t) =>
      ScaffoldMessenger.of(context).showSnackBar(SnackBar(content: Text(t)));

  Future<void> _mudarDias(int d) async {
    await prefs.setInt('dias_aviso', d);
    await Lembretes.reagendarTodos(await db.contasEmAberto(), d);
    setState(() {});
  }

  Future<void> _exportar() async {
    final json = jsonEncode(await db.exportar(diasAviso));
    final nome = 'contas-backup-${iso(hoje())}.json';
    if (Platform.isAndroid) {
      final f = File('${(await getTemporaryDirectory()).path}/$nome');
      await f.writeAsString(json);
      await SharePlus.instance.share(ShareParams(files: [XFile(f.path)]));
    } else {
      final local = await getSaveLocation(suggestedName: nome);
      if (local == null) return;
      await File(local.path).writeAsString(json);
      if (mounted) _msg('Backup salvo');
    }
  }

  Future<void> _importar() async {
    // Android: sem filtro, gerenciadores de arquivo nem sempre reconhecem .json
    final f = await openFile(
        acceptedTypeGroups:
            Platform.isAndroid ? const [] : const [XTypeGroup(label: 'JSON', extensions: ['json'])]);
    if (f == null) return;
    final Map<String, Object?> dados;
    try {
      dados = jsonDecode(await f.readAsString()) as Map<String, Object?>;
    } catch (_) {
      if (mounted) _msg('Arquivo inválido');
      return;
    }
    if (!mounted) return;
    final ok = await showDialog<bool>(
        context: context,
        builder: (ctx) => AlertDialog(
              title: const Text('Importar backup?'),
              content: const Text('Todos os dados atuais serão substituídos.'),
              actions: [
                TextButton(onPressed: () => Navigator.pop(ctx, false), child: const Text('Cancelar')),
                TextButton(onPressed: () => Navigator.pop(ctx, true), child: const Text('Substituir')),
              ],
            ));
    if (ok != true) return;
    try {
      final dias = (await db.importar(dados)).clamp(0, 10); // limite do seletor
      await prefs.setInt('dias_aviso', dias);
      await Lembretes.reagendarTodos(await db.contasEmAberto(), dias);
      setState(() {});
      if (mounted) _msg('Backup importado');
    } on FormatException catch (e) {
      if (mounted) _msg(e.message);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Configurações')),
      body: ListView(children: [
        ListTile(
          title: const Text('Avisar antes do vencimento'),
          subtitle: Lembretes.suportado ? null : const Text('No computador o aviso aparece ao abrir o app'),
          trailing: DropdownButton<int>(
            value: diasAviso,
            items: [
              for (var d = 0; d <= 10; d++)
                DropdownMenuItem(value: d, child: Text(d == 0 ? 'No dia' : '$d dia(s)')),
            ],
            onChanged: (d) => _mudarDias(d!),
          ),
        ),
        const Divider(),
        ListTile(leading: const Icon(Icons.upload), title: const Text('Exportar backup'), onTap: _exportar),
        ListTile(leading: const Icon(Icons.download), title: const Text('Importar backup'), onTap: _importar),
      ]),
    );
  }
}
```

> Se `share_plus` instalado for anterior à v11 (sem `SharePlus.instance`), use `Share.shareXFiles([XFile(f.path)])`.
